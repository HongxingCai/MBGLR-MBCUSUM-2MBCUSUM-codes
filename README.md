# Simulation codes for MBGLR, MBCUSUM and 2MBCUSUM schemes

This repository provides the implementation codes used in the manuscript:

"Some Innovative Multivariate Bayesian Schemes for Monitoring the Mean Vector with Applications to Monitoring Production Processes"

The repository includes R codes for:

1. Control-limit calibration for the MBGLR, MBCUSUM and 2MBCUSUM schemes;
2. In-control SSATS estimation;
3. Out-of-control SSATS and SSSDTS estimation;

The control limits are calibrated by Monte Carlo simulation so that the in-control \(SSATS_0\) is approximately 370.

The reported simulation results are based on 10,000 Monte Carlo replications. Due to Monte Carlo randomness, independently reproduced values may have small numerical fluctuations, but the main conclusions remain unchanged.
